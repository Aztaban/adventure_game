## D120-04 — Define the save-file envelope and status model

- [x] Define save-file format version 1 separately from the existing snapshot version.
- [x] Wrap the snapshot in a plain JSON-compatible envelope containing at minimum the file version, UTC save timestamp, and snapshot payload.
- [x] Validate envelope shape and types before calling snapshot restoration.
- [x] Distinguish missing, valid, invalid JSON, invalid envelope, unsupported file version, invalid snapshot, and unreadable-file outcomes.
- [x] Keep raw filesystem/JSON exceptions from leaking into player-facing menu code.
- [x] Do not implement migrations; unsupported versions fail safely and clearly.
- [x] Add focused envelope, timestamp, status, and unsupported-version tests.

Implemented facts:

- `game/save_file.py` owns save-file format version `1`, separately from snapshot version `1` in `game/state_snapshot.py`.
- `create_save_file_envelope()` produces only plain JSON-compatible values and normalizes aware timestamps to ISO-8601 UTC with a `Z` suffix.
- `validate_save_file_data()` requires exactly `save_format_version`, `saved_at_utc`, and `snapshot`, validates the UTC timestamp, and validates the snapshot before any session restoration.
- `SaveFileStatus` distinguishes missing, valid, invalid JSON, invalid envelope, unsupported file version, invalid snapshot, and unreadable-file outcomes.
- `inspect_save_file()` and `inspect_save_file_text()` convert filesystem, Unicode, JSON, envelope, and snapshot failures into the status model without returning raw exceptions.
- Unsupported save-file versions return `UNSUPPORTED_FILE_VERSION`; no migration or fallback path exists.
- `validate_state_snapshot()` is now the public non-mutating snapshot-validation boundary. Pygame-bound imports remain deferred until actual session restoration.

Verification notes:

- All 21 focused save-file envelope/status tests passed; all 25 focused persistence-boundary tests passed with save-path coverage included.
- A dependency-independent subset of 77 tests passed.
- The complete suite command stopped during collection with 23 errors because Pygame is unavailable; no Pygame-backed tests executed.
- Python compilation, configured line-length checks, and a no-build-isolation wheel build passed. The wheel contains `game/save_file.py` and both runtime dependencies.
- Ruff is unavailable in this environment, so the configured lint and format checks could not run.
- No manual gameplay check is required because this task does not connect validation to application modes or mutate a running session.
- `CHANGELOG.md` remains untouched; milestone changelog work is deferred to D120-10 as requested.

Recommended shape:

```json
{
  "save_format_version": 1,
  "saved_at_utc": "<ISO-8601 UTC timestamp>",
  "snapshot": {}
}
```
